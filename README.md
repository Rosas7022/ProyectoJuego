
# ProyectoJuego

## Descripción
Este proyecto es un juego desarrollado en Java para la materia de Fundamentos de Programación de CESUN Universidad.

El objetivo es adivinar un número aleatorio del 1 al 100.

## Funcionamiento
El programa genera un número secreto y el jugador debe intentar adivinarlo.

Si el número ingresado es menor, el programa indica que el número secreto es mayor.

Si el número ingresado es mayor, el programa indica que el número secreto es menor.

Cuando el jugador adivina, el programa muestra un mensaje de felicitación y la cantidad de intentos realizados.

## Archivos del proyecto
- Principal.java: contiene el programa principal.
- Funciones.java: contiene los métodos del juego.
- .gitignore: excluye archivos innecesarios de Git.

## Instrucciones de ejecución
1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Tener instalado Java y sus herramientas de desarrollo.
3. Abrir Principal.java.
4. Presionar Run para ejecutar el programa.
5. Ingresar números del 1 al 100 hasta adivinar.
